# İstanbul Match · Hacivat & Karagöz's Istanbul Tour

Hacivat & Karagöz take you stop by stop across a real map of Istanbul, from Sultanahmet to Kadıköy.

```bash
npm install
npm run dev        # play in the browser
npm test           # engine tests (Vitest)
npm run build
```

Android / Google Play: see [docs/ANDROID.md](docs/ANDROID.md). Project layout and conventions: [CLAUDE.md](CLAUDE.md).

Tile, special and booster art: [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (3D), MIT License.
